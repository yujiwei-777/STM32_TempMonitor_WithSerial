# STM32_TempMonitor_WithSerial
课程作业
基于 STM32F10x 的温度实时监测系统，支持 OLED 本地显示 + 串口数据上传，超温蜂鸣器报警，适用于嵌入式温度采集与监控场景。

## 项目简介
本项目基于 **STM32F103C8T6** 实现温度监测功能，通过 NTC 热敏电阻采集环境温度，实时在 0.96 寸 I2C OLED 屏上显示，并通过 **USART1 串口单向上传温度数据**至电脑。当温度超过设定阈值时，板载蜂鸣器自动报警，系统可独立稳定运行，也可作为数据采集节点配合上位机记录数据。

### 核心特点
- 双端显示：温度数据同步展示在 OLED 屏幕与电脑串口助手
- 极简可靠：串口发送数据
- 精准测温：采用 Steinhart-Hart 公式校准 NTC 热敏电阻
- 超温报警：蜂鸣器警报，温度阈值可灵活配置
- 适用场景：可直接作为温度采集节点，支持串口数据记录

## 硬件接线
所有模块共地，电平统一使用 3.3V 避免损坏硬件

### NTC 热敏电阻
- VCC → 3.3V
- GND → GND
- AO → **PA0**（ADC 通道 0）

### OLED（I2C）
- VCC → 3.3V
- GND → GND
- SCL → **PB8**（I2C1_SCL）
- SDA → **PB9**（I2C1_SDA）

### 蜂鸣器
- VCC → 3.3V / 5V
- GND → GND
- I/O → **PB12**（GPIO 输出）

### USB 转 TTL（串口）
- VCC → 3.3V
- GND → GND
- TXD → **PA10**（USART1_RX）
- RXD → **PA9**（USART1_TX）

> 注意：串口必须**交叉连接**（模块 TX → 单片机 RX，模块 RX → 单片机 TX）

### 核心模块说明
1. **串口模块**
   - 初始化 USART1，波特率 115200，8N1 格式
   - 提供字符串/浮点数发送函数
   - 仅发送数据，关闭接收中断，系统更稳定

2. **温度采集模块**
   - ADC 采样 NTC 模拟电压
   - 使用校准公式转换为实际温度
   - 数据供 OLED 显示与串口上传

3. **主循环逻辑**
   - 200ms 采集一次温度
   - 实时刷新 OLED 显示
   - 超温自动触发蜂鸣器
   - 1 秒通过串口发送一次温度数据

## 串口数据说明
### 串口参数
- 波特率：115200
- 数据位：8
- 停止位：1
- 校验位：无

### 数据格式
系统每秒自动发送一行数据，示例：
```
Temp: 23.4 C
Temp: 23.6 C
Temp: 23.5 C
```

### 查看方式
使用 XCOM、sscom 等串口调试助手，打开对应 COM 口即可接收。


## 使用说明
### 1. 编译与下载
1. 用 Keil 打开 `Project.uvprojx` 工程
2. 编译工程，无报错后通过下载器烧录至 STM32

### 2. 上电运行
- OLED 屏幕实时显示当前温度
- 串口助手每秒接收一条温度数据
- 温度超阈值时蜂鸣器持续报警

### 3. 参数配置
- 修改报警阈值：在 `main.c` 中修改宏定义
  ```c
  #define TEMP_THRESHOLD  40  // 单位：℃
  ```
- 温度校准：在 `ADC.c` 中调整 `B_VALUE` 和 `SERIES_RESISTOR`

## 常见问题
### Q1：串口收不到数据？
- 检查串口接线（TX/RX 交叉连接）
- 确认共地、波特率设置为 115200
- 确认 `Serial_Init()` 已在主函数调用

### Q2：串口数据乱码？
- 确保串口助手波特率与程序一致
- 检查 STM32 系统时钟配置为 72MHz

### Q3：OLED 正常但串口无输出？
- 检查 PA9/PA10 是否被其他外设占用
- 确认串口模块已正确初始化

### Q4：关闭串口发送？
注释主循环中的串口发送代码块即可节省资源
