# STM32_TempMonitor_WithSerial

课程作业  
基于 STM32F10x 的温度实时监测系统，支持 OLED 本地显示 + 串口数据上传，超温时蜂鸣器报警并自动启动散热电机，适用于嵌入式温度采集与散热控制场景。

---

## 项目简介

本项目基于 **STM32F103C8T6** 实现温度监测与自动散热功能。通过 NTC 热敏电阻采集环境温度，实时在 0.96 寸 I2C OLED 屏上显示，并通过 **USART1 串口单向（仅发送）上传温度数据**至电脑。当温度超过设定阈值时，系统自动触发蜂鸣器间歇报警，同时启动直流电机（散热风扇）旋转，帮助降温。系统可独立稳定运行，也可作为数据采集节点配合上位机记录数据。

### 核心特点

- **双端显示**：温度数据同步展示在 OLED 屏幕与电脑串口助手
- **极简可靠**：串口仅发送数据，不接收命令，避免干扰
- **精准测温**：采用 Steinhart-Hart 公式校准 NTC 热敏电阻
- **智能散热**：超温时自动启动电机，温度正常后自动停止
- **声光报警**：蜂鸣器间歇鸣叫，阈值可灵活配置
- **适用场景**：嵌入式温控散热系统、实验数据采集

## 硬件接线

**注意**：所有模块与 STM32 共地，逻辑电平统一使用 **3.3V**；电机驱动模块需外接电机电源。

### NTC 热敏电阻（AO 输出）
| 引脚 | 连接至 STM32 |
|------|--------------|
| VCC  | 3.3V         |
| GND  | GND          |
| AO   | **PA0**（ADC 通道 0） |

### OLED 显示屏（I2C 接口）
| 引脚 | 连接至 STM32 |
|------|--------------|
| VCC  | 3.3V         |
| GND  | GND          |
| SCL  | **PB6**（I2C1_SCL） |
| SDA  | **PB7**（I2C1_SDA） |

### 蜂鸣器（有源，高电平触发）
| 引脚 | 连接至 STM32 |
|------|--------------|
| VCC  | 3.3V         |
| GND  | GND          |
| I/O  | **PA8**（GPIO 输出） |

### 直流电机驱动
- **PWM 调速**：将 PWMA连接至 **PA2**（TIM2_CH3）
- **方向控制**：将 L298N 的 IN1、IN2 分别连接至 **PA4** 和 **PA5**
  - PA4=1, PA5=0 → 正转
  - PA4=0, PA5=1 → 反转
- **电源**：VCC接vcc，GND 与 STM32 共地 vcc接stby vm接5v
- **电机** 一根接A01 一根接A02


> 若使用 L9110S 等模块，接线类似，请参考其数据手册。

### USB 转 TTL 模块（CH340 / CP2102）
| 引脚 | 连接至 STM32 |
|------|--------------|
| VCC  | 3.3V         |
| GND  | GND          |
| TXD  | **PA10**（USART1_RX）|
| RXD  | **PA9**（USART1_TX）|

> **串口连接特别提醒**：必须**交叉连接** —— 模块的 TXD 接单片机的 RX（PA10），模块的 RXD 接单片机的 TX（PA9）。

### 核心模块说明

#### 1. 温度采集（ADC.c）
- 使用 **PA0** 模拟输入，ADC1 通道 0
- 单次转换，采样时间 239.5 周期，10 次平均滤波
- 采用 **Beta 参数方程**将电压转换为温度（Steinhart-Hart 简化公式）

#### 2. OLED 显示（OLED.c）
- I2C 接口驱动 SSD1306，地址 0x78
- 第一行显示 `Temp: xx.x C`
- 第二行显示 `Normal` 或 `Warning`

#### 3. 蜂鸣器报警（Buzzer.c）
- GPIO PA8 输出高电平触发
- 超温时 **每 200ms 翻转一次**，实现间歇式警报
- 温度正常后立即关闭

#### 4. 直流电机控制（Motor.c + PWM.c）
- **PWM 驱动**：TIM2_CH3（PA2），频率约 10kHz，占空比可调
- **方向控制**：PA4、PA5 控制 H 桥逻辑
- **自动模式**：超温时正转，占空比 70%；正常时停止
- 扩展性：可改为手动控制（需增加串口命令）

#### 5. 串口通信（Serial.c）
- USART1 初始化，115200 波特率，8N1 格式
- 提供 `Serial_SendString()`、`Serial_SendFloat()` 等函数
- 主循环每 **1 秒** 主动发送一次温度数据

#### 6. 主循环逻辑（main.c）
- 每 200ms 采集一次温度
- 刷新 OLED 显示，判断是否超温
- 超温时：蜂鸣器间歇鸣叫，电机正转（70% 占空比）
- 正常时：蜂鸣器静音，电机停止
- 每隔 1 秒通过串口发送温度数据

## 使用说明

### 1. 编译与下载
- 使用 Keil MDK 5 打开工程
- 确保已添加所有硬件驱动文件（`.c` / `.h`）
- 编译工程（无错误），通过 ST-Link / J-Link / 串口下载器烧录至 STM32

### 2. 上电运行
- 系统上电后，OLED 屏幕显示当前温度
- 打开串口调试助手，每秒接收一次温度数据
- 当温度超过预设阈值（默认 40℃）时：
  - 蜂鸣器间歇鸣叫
  - 电机正转（散热风扇旋转）
- 温度回落到阈值以下后，蜂鸣器和电机均停止

编辑 `main.c` 文件中的宏定义：
```c

常见问题
Q1：串口收不到数据？
检查 USB 转 TTL 模块接线是否交叉连接（TXD → PA10，RXD → PA9）

确认模块与 STM32 共地（GND 相连）

确认串口助手的波特率设置为 115200

确认 Serial_Init() 已在 main() 中调用

Q2：串口数据乱码？
确保串口助手波特率与程序一致（115200）

检查 STM32 系统时钟配置为 72MHz（标准库默认）

尝试更换 USB 转 TTL 模块或更换电脑 USB 口

Q3：OLED 正常但串口无输出？
检查 PA9（TX）、PA10（RX）引脚是否被其他外设占用

检查 Serial_SendString() 等函数是否正确调用

确认串口模块供电正常（3.3V）

Q4：电机不转？
检查电机驱动模块供电是否正常（电机需独立供电）

确认 PA2（PWM）、PA4、PA5 接线正确

用万用表测量 PA2 是否有 PWM 波形（超温时）

检查 PA4、PA5 逻辑电平：超温时 PA4 应为高，PA5 应为低

确保电机驱动模块的使能端已连接（如 L298N 的 ENA 接到 PA2 或直接短接至高电平）

Q5：电机一直转或不受控？
检查方向控制引脚是否虚焊或短路

确认 Motor_SetSpeed(0) 在正常温度下被调用

检查 PWM 初始化是否正确（TIM2_CH3）

Q6：蜂鸣器不响或一直响？
检查蜂鸣器模块是否高电平触发（有源蜂鸣器）

测量 PA8 引脚电平是否在超温时周期性变化

调整 buzzerBlinkCounter 的阈值可改变报警频率
